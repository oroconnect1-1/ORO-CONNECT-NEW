# ORO-CONNECT

**ORO-CONNECT** marsariitii fi appii mobaayilaa (Progressive Web App / Android APK) hawaasa walqunnamsiisuu fi odeeffannoo qooduuf qophaa'edha.

## 🚀 Amalaalee Ijoo (Features)
- **Progressive Web App (PWA):** Bilbilaa fi kompiitara irratti saffisaan hojjeta, akkasumas *offline* ni deeggara.
- **Android App (.apk):** Bilbila Android irratti fe'amee akka appii idileetti fayyadamuu ni danda'ama.
- **Firebase Integration:** Eegumsa ragaa (Firestore Security Rules), authentication, fi hosting amanamaa fayyadama.
- **Automated Deployment:** GitHub Actions fayyadamuun jijjiiramni koodii yeroo godhamu ofumaan gara Firebase Hosting irratti *deploy* ta'a.

## 🛠️ Teeknooloojiiwwan Fayyadamne (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend & Hosting:** Firebase (Firestore, Hosting, Cloud Messaging) & GitHub Pages
- **CI/CD & Security:** GitHub Actions & GitHub Secrets

Ragaan dhuunfaa fi *API keys* hundi **GitHub Secrets** fi **Firebase Security Rules** fayyadamuun eegamanii jiru.
